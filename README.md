Debian packages of linux configs for the Nintendo Switch
========================================================

## Updating:
Grab the tar.gz of the new version of the package you want to update, then cd to
the directory containing the old versions packaging and run:
`$ uupdate -v newversion ../package-newversion.tar.gz`

`$ cd ../package-newversion'

`$ dch`

Then commit the new versions packaging to this branch and ping bylaws in discord.
